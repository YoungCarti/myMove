# myMove FYP2 Project Poster Content Guide

## 1. Project Title & Abstract
**MYMOVE: AN IOT-ENABLED SMART PARKING RESERVATION AND PRIVACY-PRESERVING VEHICLE COMMUNICATION SYSTEM**

> “myMove is a smart parking ecosystem that integrates IoT hardware, a Flutter mobile app, and a serverless web backend to streamline parking space reservation, provide real-time slot occupancy tracking, and resolve double-parking situations safely through privacy-preserving QR code notifications.”

---

## 2. Project Objectives
1. **To study and analyze** existing urban parking management systems and vehicle contact methods to identify key security and operational limitations.
2. **To design and develop** the myMove smart parking solution integrating ESP32 IoT sensors, Firebase Cloud Services, Flutter mobile app, and Stripe payment gateway.
3. **To evaluate system performance and user satisfaction** through rigorous unit, integration, and User Acceptance Testing (UAT) with target users.

---

## 3. Results: Feature Effectiveness & Key Findings

![Feature Effectiveness Chart](feature_effectiveness_chart.png)

### Key Satisfaction Highlights
* **> 95% agreed** – 🅿️ **Real-Time Parking Grid**: Real-time interactive grid accurately displays spot availability.
* **> 90% agreed** – 🛡️ **Windshield QR Contact**: Privacy-preserving QR contact eliminates visible phone numbers.
* **> 90% agreed** – 💳 **Spot Booking & Stripe**: In-app spot booking and Stripe payment processing is seamless and secure.
* **> 85% agreed** – 🔒 **Vehicle Profile & 2FA**: Vehicle profile setup and Two-Factor Authentication security configuration is simple and intuitive.

---

## 4. Conclusion & Project Impact

> **“myMove successfully addresses urban parking stress and double-parking conflicts by providing a seamless, real-time IoT parking grid paired with a privacy-preserving QR communication platform.”**

### Key Benefits of myMove 🚗
* 🅿️ **Real-Time Visibility**: Live IoT spot monitoring reduces time wasted searching for parking slots.
* 🛡️ **Privacy-Preserving Contact**: Anonymous windshield QR code notifications eliminate the need to expose personal phone numbers on vehicles.
* 💳 **Seamless Transactions**: Instant spot reservations and secure cashless mobile checkout powered by Stripe.
* ⚡ **Zero-Install Guest Access**: Web scanner portal allows guest drivers to notify vehicle owners instantly without downloading the app.
